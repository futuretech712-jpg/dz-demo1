# Detailerz – demo web stranica

Statična stranica (HTML, CSS, JS), bez build koraka.

- `index.html` – stranica i svi podaci (cijene su u objektu `DATA` na dnu datoteke)
- `legal.js` – pravila privatnosti, uvjeti poslovanja, politika kolačića
- `img/` – fotografije (Unsplash, privremeno)
- `robots.txt` i `<meta name="robots" content="noindex">` – demo se ne prikazuje na tražilicama. Za pravu objavu obriši oboje.
